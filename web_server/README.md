# alu-system_engineering-devops

Projects for the ALU System Engineering & DevOps track.

## web_server

Setting up and configuring a web server with Nginx on Ubuntu 16.04.

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server with `scp` (4 parameters, strict host key checking disabled) |
| `1-install_nginx_web_server` | Installs Nginx and serves "Holberton School for the win!" on port 80 |
| `2-setup_a_domain_name` | Domain name pointing to the web server |
| `3-redirection` | Configures a 301 redirect for `/redirect_me` |
| `4-not_found_page_404` | Configures a custom 404 page containing "Ceci n'est pas une page" |
| `5-design_a_beautiful_404_page.html` | Creative 404 page design |

All Bash scripts start with `#!/usr/bin/env bash`, are executable, and pass Shellcheck.
